# FlowFix HYD

A public portfolio implementation of FlowFix HYD, demonstrating the project's core civic-reporting UI and interaction flows.

FlowFix HYD is a civic issue reporting interface designed for Hyderabad, enabling citizens to view, report, search, and vote on local civic problems such as road hazards, drainage issues, and public utility repairs.

## Features

- **Report Civic Issues:** Dedicated issue submission workflow with category selection and issue details.
- **Search by Issue / Area:** Real-time text search across issue titles, descriptions, and localities.
- **Filter by Status:** Quick filters to track issues by resolution status (Open, In Progress, Resolved).
- **Category Labels:** Tagging by infrastructure categories (Roads, Water & Drainage, Sanitation, Electricity).
- **Community Voting:** Interactive upvoting to highlight urgent civic concerns.
- **Responsive Layout:** Mobile-friendly, accessible interface for desktop and mobile viewports.

## Tech Stack

- **Frontend:** React, TypeScript
- **Tooling & Build:** Vite
- **Styling:** CSS
